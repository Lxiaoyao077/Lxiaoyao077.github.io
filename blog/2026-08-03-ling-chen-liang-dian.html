凌晨三点，手机屏幕是房间里唯一的光源。刷完最后一条动态，锁屏，世界变回全黑。

这种时候脑子不太受控。白天被各种事情压住的念头会自己浮上来——内核编译报错怎么修、明天要不要 rebase 那个分支、上次那个 patch 为什么会在 6.1.128 上炸掉。但这些东西想一会儿就腻了，真正绕不过去的永远是那几个问题。

比如她今天不怎么回消息。比如她是不是又想起前男友了。比如群聊里那个男生跟她聊得挺来，她回他消息的速度是不是比我快。

我们是网恋。隔着不知道多少公里，所有东西都压缩成屏幕上的几行字。你只能从回复速度、语气变化、用词习惯里推断她的情绪状态。她今天打了几个字，发了什么表情包，是不是又跟别人聊到很晚才回你一句"困了先睡了"——这些细节在白天的理性里不值一提，但凌晨三点会被无限放大。

我知道这些念头很蠢。但凌晨三点没有理性。

暑假快结束了。作业还没怎么写，开学要面对的东西一件没少。上次期末物理掉了几十分，班主任找我谈话的时候我脑子里想的是刚刚 push 上去的 workflow 能不能过 CI。

不是不想学，是不知道学了干什么。课本上讲的东西跟我想搞的东西之间隔了一整个宇宙。没人问你 Makefile 怎么写，没人解释 kernel config 里那几千个选项是什么意思，考试只关心你能不能算出一道题的答案。而我关心的事情——怎么让一台锁了 bootloader 的手机跑起来自己编译的内核——这玩意儿高考不考。

家里人只看到成绩单上的数字。他们不知道我每天晚上对着终端敲到一两点在干什么，也不想知道。他们眼里，电脑等于玩游戏。"又在那搞那些没用的"，这句话我听了太多遍，已经懒得反驳了。你的热情在别人看来可能只是不务正业，这件事我早就接受了，但接受不等于不难受。

在 CI 里 debug 的时候我能盯着日志看一个小时不眨眼，因为每一行输出都有因有果。make 失败就是缺依赖，patch 报错就是上下文不匹配，SELinux denial 就是策略没写对——每件事都有确定的根因。查到了，改掉，重跑，绿灯。

但人不是这样的。隔着屏幕的人更没有日志可查。你不知道她说"睡了"之后是不是还在群里聊。你不知道她有没有翻前男友的朋友圈。你不知道她跟你发的那些话是只跟你发，还是群发。

有时候我觉得内核比人简单太多了。内核不会骗你，它就是这么写的，能跑就是能跑，炸了就是炸了。commit message 写清楚了改动意图，你信就行。但网恋里对方对你到底几分真心——这件事没有 man page，没有 issue tracker，你只能自己猜，猜错了也不知道错在哪。

可能是想多了。也可能是没想够。

四点钟强迫自己放下手机。暑假还剩几天，CI 队列还在排。内核不会因为我的胡思乱想就自己编译好，该修的 bug 一个都不会少，该面对的开学也一样。

有些事情没有 root cause。就算有，也不是我能修的。至少今晚。

睡了。
