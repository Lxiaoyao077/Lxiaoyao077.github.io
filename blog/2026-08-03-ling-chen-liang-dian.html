凌晨两点，手机屏幕是房间里唯一的光源。刷完最后一条动态，锁屏，世界变回全黑。

这种时候脑子不太受控。白天被各种事情压住的念头会自己浮上来——内核编译报错怎么修、明天要不要 rebase 那个分支、上次那个 patch 为什么会在 6.1.128 上炸掉。但这些东西想一会儿就腻了，真正绕不过去的永远是那几个问题。

比如她今天跟谁吃了饭，为什么不回消息。比如那个男同事为什么总在她的朋友圈下面秒赞。比如她刚才那个微信弹出来的时候下意识把屏幕往自己那边侧了一下。

我知道这些念头很蠢。但凌晨两点没有理性。

在 CI 里 debug 的时候我能盯着日志看一个小时不眨眼，因为每一行输出都有因有果。make 失败就是缺依赖，patch 报错就是上下文不匹配，SELinux denial 就是策略没写对——每件事都有确定的根因。查到了，改掉，重跑，绿灯。

但人不是这样的。人的行为没有日志可查，没有 dmesg 能告诉你刚才那句话背后的情绪是什么，没有 git blame 能帮你找到一段关系里是谁先开始冷淡的。

有时候我觉得内核比人简单太多了。内核不会骗你，它就是这么写的，能跑就是能跑，炸了就是炸了。commit message 写清楚了改动意图，你信就行。但人说的话里有多少是真的，多少是出于礼貌，多少是为了省掉解释的麻烦——你不知道。

可能是想多了。也可能是没想够。

三点钟强迫自己放下手机。明天还要推一个版本，CI 队列还在排。内核不会因为我的胡思乱想就自己编译好，该修的 bug 一个都不会少。有些事情没有 root cause，就算有，也不是我能修的。

睡了。
