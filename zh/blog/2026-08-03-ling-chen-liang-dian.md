---
title: 凌霄三点
date: 2026-08-03
description: 一些睡不着的时候想的事。
---

凌霄三点，手机屏幕是房间里唯一的光源。刷完最后一条动态，锁屏，世界变回全黑。

这种时候脑子不太受控。白天被各种事情压住的念头会自己浮上来——内核编译报错怎么修、明天要不要 rebase 那个分支、上次那个 patch 为什么会在 6.1.128 上炸掉。但这些东西想一会儿就腻了，真正绕不过去的永远是那几个问题。

比如她今天跟谁吃了饭，为什么不回消息。比如那个男同事为什么总在她的朋友圈下面秒赞。比如她刚才那个微信弹出来的时候下意识把屏幕往自己那边侧了一下。

我知道这些念头很蠢。但凌霄三点没有理性。

然后是学业。书包里还有两张没写的卷子，下周一模。上次月考物理掉了几十分，班主任找我谈话的时候我脑子里想的是刚刚 push 上去的 workflow 能不能过 CI。

不是不想学，是不知道学了干什么。课本上讲的东西跟我想搞的东西之间隔了一整个宇宙。没人问你 Makefile 怎么写，没人解释 kernel config 里那几千个选项是什么意思，考试只关心你能不能算出一道题的答案。而我关心的事情——怎么让一台锁了 bootloader 的手机跑起来自己编译的内核——这玩意儿高考不考。

家里人只看到成绩单上的数字。他们不知道我每天晚上对着终端敲到一两点在干什么，也不想知道。他们眼里，电脑等于玩游戏。"又在那搞那些没用的"，这句话我听了太多遍，已经懒得反驳了。你的热情在别人看来可能只是不务正业，这件事我早就接受了，但接受不等于不难受。

在 CI 里 debug 的时候我能盯着日志看一个小时不眨眼，因为每一行输出都有因有果。`make` 失败就是缺依赖，`patch` 报错就是上下文不匹配，SELinux denial 就是策略没写对——每件事都有确定的根因。查到了，改掉，重跑，绿灯。

但人不是这样的。人的行为没有日志可查，没有 `dmesg` 能告诉你刚才那句话背后的情绪是什么，没有 `git blame` 能帮你找到一段关系里是谁先开始冷淡的。生活也不会因为你努力了就给你绿灯——考试题做不出来就是做不出来，成绩单上的数字比你的任何一行代码都更能决定别人怎么看你。

有时候我觉得内核比生活简单太多了。内核不会骗你，它就是这么写的，能跑就是能跑，炸了就是炸了。commit message 写清楚了改动意图，你信就行。但人说的话里有多少是真的，多少是出于礼貌，多少是为了省掉解释的麻烦——你不知道。教室里的社交、家里人的期望、喜欢的人到底怎么看你——这些事情没有 man page，没有 issue tracker，你只能自己试，试错了也不知道错在哪。

可能是想多了。也可能是没想够。

四点钟强迫自己放下手机。明天还要上课，还要推一个版本，CI 队列还在排。内核不会因为我的胡思乱想就自己编译好，该修的 bug 一个都不会少，该考的试也一样。

有些事情没有 root cause。就算有，也不是我能修的。至少今晚。

睡了。
